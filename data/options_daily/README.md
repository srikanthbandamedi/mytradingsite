# Daily calls vs puts

One row per stock per trading day, saved right after the 3:00 PM CT close from Robinhood's options scanner (all expirations added up).

- call_vol / put_vol: contracts traded that day
- put_call_ratio: put_vol / call_vol
- call_oi / put_oi: open interest
- call_premium / put_premium: dollars traded
- call_vol_avg10 / put_vol_avg10: Robinhood's 10-day average volume

Stocks: the bot's S&P 201-300 and Nasdaq 100 lists for that day. Started 2026-11-09.
